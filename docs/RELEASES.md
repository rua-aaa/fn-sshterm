# Releases / 安装包

从 [Releases](https://github.com/rua-aaa/fn-sshterm/releases) 下载 fpk。

| 文件 | 架构 | 说明 |
| --- | --- | --- |
| sshterm-1.1.0-all.fpk | all | 通用包，推荐 |
| sshterm-1.1.0-x86.fpk | x86 | x86_64 NAS |
| sshterm-1.1.0-arm.fpk | arm | arm64 NAS |
| sshterm-1.0.9-ui.fpk | all | 1.0.9 UI 版 |

安装前请在应用中心安装 **Node.js v22**，再安装 fpk 并启动。
